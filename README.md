## Featured work

### 📚 Top Papers Creator

Automated pipeline for producing academic economics papers.  
Claude supports reasoning, Python handles execution, and human reviewers  
participate at key checkpoints.

### 🔗 DAGs and Causal Machine Learning

Notebooks and applications related to directed acyclic graphs,  
causal inference and machine learning.

### 💊 FarmaciaAI

AI-powered project for reading medical prescriptions, identifying  
generic alternatives and comparing medicine prices in Peru.

### 🏫 Education Research

Data analysis and experimental tools for studying education,  
gender and leadership in Peruvian schools.
